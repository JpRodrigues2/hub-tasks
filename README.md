# Hub de Tasks

Lê as suas tasks (Funifier PM, Bnexo, Jira), manda a lista no Telegram e despacha as que você escolher para sessões do
Claude Code no Orca, avisando quando terminam ou precisam de você.

- **Para instalar e usar:** comece por [`instalacao/README.md`](instalacao/README.md).
- **Para desenvolver o hub:** [`docs/README.md`](docs/README.md).
